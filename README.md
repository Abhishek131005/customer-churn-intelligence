# Customer Churn & Revenue Intelligence Platform

An end-to-end machine learning system for identifying customers at risk of churn, understanding the factors driving churn, estimating revenue at risk, and prioritizing customer retention efforts.

> 🚧 This project is currently under active development.

## Problem Statement

Subscription-based businesses lose recurring revenue when customers discontinue their services. Predicting churn alone is not enough: businesses also need to understand why customers are leaving and which customers should be prioritized for retention.

This project builds an end-to-end customer intelligence system that combines data analysis, machine learning, explainability, and revenue-risk analysis to support retention decisions.

## Project Goals

- Analyze customer behavior and churn patterns
- Identify major factors associated with customer churn
- Build and evaluate machine learning models for churn prediction
- Estimate customer-level revenue at risk
- Explain predictions using model explainability techniques
- Prioritize high-risk customers for retention
- Expose predictions through an API
- Build an interactive analytics and prediction dashboard
